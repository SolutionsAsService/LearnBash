Resources

Where to learn more

A short list, not a long one. Links were not checked from the build environment; if one is dead, tell us.

The list

  • The GNU Bash Reference Manual

    The authoritative description of every feature. Dense; search it rather than read it through.

  • ShellCheck

    Paste a script and it points out quoting mistakes, portability problems and common bugs, each with an explanation.

  • Greg's Wiki: BashGuide and BashPitfalls

    A careful, opinionated guide, and a list of the mistakes almost everyone makes once.

  • tldr pages

    Short, practical examples for thousands of commands. The fastest way to remember a flag.

  • explainshell

    Paste a command and it matches each part to the manual page text. A larger cousin of the explainer on this site.

  • Advanced Bash-Scripting Guide

    A huge collection of examples. Parts are dated and some habits it shows are discouraged today; read it with ShellCheck open.

  • man bash, help and info

    Already on your computer: man bash for the manual, help NAME for built-ins, NAME --help for most programs.

The previous version of this site linked to wiki.bash-hackers.org. It is not listed here because it could not be checked, and Greg's Wiki above covers much of the same ground.
