What it knows, and what it does not

  • It knows the 42 commands and 120 flags in the command reference. Anything else is shown as unknown.
  • It splits at pipes and operators (| && || ;), reads quotes, and notices redirections such as >, which empties its target file before the command even starts.
  • It does not understand every shell feature: loops, functions and nested substitutions are shown as plain text.
  • It is a reading aid, not a safety scanner. A command it calls harmless can still be wrong for your situation.
