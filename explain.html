What it knows, and what it does not

  • It knows the 45 commands and 109 flags in the command reference. Anything else is shown as unknown.
  • It splits at pipes and operators (| && || ;), reads quotes, and notices redirections such as >, which empties its target file before the command even starts.
  • It looks inside $( ), sh -c, env, xargs, find -exec and loops, and rates what it finds there. It skips here-document text and comments.
  • When part of a line cannot be analysed (an unknown command, eval, a function, a script file), the verdict is Can't tell, never a reassuring one.
  • It is a reading aid, not a safety scanner. A line it rates "Only reads" can still be wrong for your situation, and nothing replaces reading a command before you run it.

The marks

  • Only readsDoes not change your files or the system. It can still change the current shell session (cd, export and alias do).
  • Changes thingsCreates or modifies files or system state, without removing what was there.
  • Can delete dataCan remove or overwrite existing data in ordinary use, and there is no undo.
  • Can't tellPart of the line could not be analysed, so it is not called safe.
