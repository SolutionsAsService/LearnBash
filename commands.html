42 commands, and what each can do

Each command carries a mark for the worst it can do in its everyday form; a flag that is more dangerous than the command says so.

  • Only readsDoes not change files or the system. (It may change the current shell session.)
  • Changes thingsCreates, modifies or moves files or system state.
  • Can delete dataCan permanently remove or overwrite data. There is no undo.

GNU (Linux) flags are shown; where macOS/BSD differs, the entry says so.

Find a command

alias

Only reads

Give a command another name for this session.

alias [NAME=VALUE]

Aliases are lost when the shell exits; put them in ~/.bashrc to keep them. Scripts do not see them.

awk

Only reads

Process text one record (line) at a time, split into fields.

awk [-F SEP] 'PATTERN { ACTION }' [FILE]...

Examples avoid features only GNU awk has, so they behave the same under mawk and macOS awk.

Flags

  • -FField separator.
  • $1, $2, ...The first, second, ... field of the current line; $0 is the whole line.
  • NRThe number of the current line.
  • NFThe number of fields on the current line.

cd

Only reads

Change the current directory of the shell.

A shell builtin: it changes where the shell is, not any file.

Flags

  • ~Your home directory (also the default when no argument is given).
  • ..The parent directory.

Changes things

Change who can read, write or run a file.

Flags

  • 644Octal: owner read and write, everyone else read only.
  • 755Octal: owner everything, others read and execute.
  • -RApply to a directory and everything in it.Changes things

cp

Changes things

Copy files and directories.

cp [OPTION]... SOURCE... DEST

By default cp overwrites an existing destination without asking. -i asks first; -n never overwrites (recent GNU versions warn that its behaviour is non-portable and suggest --update=none).

Flags

  • -rCopy directories recursively (also -R).
  • -iAsk before overwriting an existing file.
  • -nNever overwrite an existing file.
  • -vPrint each copy as it happens.
  • -pKeep mode, ownership and timestamps.

find

Only reads

Search a directory tree for files by name, type, age or size.

find [PATH]... [EXPRESSION]

Without -delete or -exec, find only reads. It lists matches in whatever order the file system gives them, so the examples sort the result.

Flags

  • -nameMatch the file name against a glob such as '*.txt' (quote it).
  • -typef for files, d for directories.
  • -mtimeModified N days ago; +N means more than N, -N less than N.
  • -sizeFile size, such as +1M.
  • -maxdepthDo not go deeper than N levels.
  • -execRun a command on each match; {} stands for the file and \; ends the command.Changes things
  • -deleteDelete every match. Put it last, and run the same find without it first.Can delete data

grep

Only reads

Print lines that match a pattern.

grep [OPTION]... PATTERN [FILE]...

Exit status is 0 if something matched, 1 if nothing did, which scripts use in if statements.

Flags

  • -iIgnore case.
  • -vInvert: print lines that do not match.
  • -nShow line numbers.
  • -rSearch directories recursively.
  • -cPrint only the number of matching lines.
  • -lPrint only the names of files that match.
  • -wMatch whole words only.
  • -EUse extended regular expressions.
  • -oPrint only the matching part of each line.
  • -FTreat the pattern as a fixed string, not a regular expression.

ls

Only reads

List the contents of a directory.

ls [OPTION]... [FILE]...

Colour and column layout depend on your terminal; output here is plain.

Flags

  • -lLong format: permissions, owner, size and date.
  • -aInclude hidden entries (names starting with a dot).
  • -hWith -l, print sizes like 1K or 234M.
  • -tSort by modification time, newest first.
  • -rReverse the sort order.
  • -RList subdirectories recursively.
  • -1One entry per line.
  • -SSort by size, largest first (GNU and BSD).

xargs

Changes things

Build and run commands from standard input.

xargs [OPTION]... COMMAND [ARG]...

It runs whatever command you give it, so it is as dangerous as that command.

Flags
