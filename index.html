Know what a command can do before you run it

Every command and flag in the reference carries a mark. A command that only reads is safe to try anywhere. One that changes things deserves a second look. One that can delete data deserves a pause.

  • Only readsDoes not change files or the system. (It may change the current shell session.)
  • Changes thingsCreates, modifies or moves files or system state.
  • Can delete dataCan permanently remove or overwrite data. There is no undo.
