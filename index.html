Know what a command can do before you run it

Every command in the reference carries a mark for what it can do in ordinary use, and a flag that is riskier than its command says so. A command marked "Only reads" will not change your files in its everyday form; check the marks on its flags too. One that changes things deserves a second look, and one that can delete data deserves a pause.

  • Only readsDoes not change your files or the system. It can still change the current shell session (cd, export and alias do).
  • Changes thingsCreates or modifies files or system state, without removing what was there.
  • Can delete dataCan remove or overwrite existing data in ordinary use, and there is no undo.
